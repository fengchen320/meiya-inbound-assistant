# 日期与注册证号归一化规范（实测归纳）

## 一、已观测到的日期格式（同一系统内并存，必须全部支持）

| 来源 | 原始值 | 含义 | 归一化 |
|---|---|---|---|
| e看牙模板-生产日期 | `1777996800000` | Excel/JS **epoch 毫秒**时间戳（UTC 2026-05-06T00:00:00Z） | 按 UTC+8 取日期 → 2026-05-06 |
| e看牙模板-有效期 | `2030-05-05` | ISO 短横线 | 直接采用 |
| 供应商清单-生产日期 | `202506` | **仅年到月**，缺失日 | 补 01 → 2025-06-01，但 confidence=0.7，标记 `incomplete_date` |
| 供应商清单-有效期至 | `20280623` | YYYYMMDD 紧凑型 | 2028-06-23 |
| 供应商清单-发货日期 | `20260630` | YYYYMMDD 紧凑型 | 2026-06-30 |
| 供货商对账单-生产日期 | `2026-06-23` | ISO | 直接采用 |
| 梅苗苗订单页 | `2026-06-30 09:29:20` | 日期+时间 | 取日期部分 |
| 牙e在线订单页 | `2026-11-18 13:16:36` | 日期+时间 | 取日期部分 |

**判定顺序（严禁按「看起来像」猜测）**
1. 长度 10–13 且纯数字且 > 10^11 → epoch 毫秒。
2. 长度 8 且纯数字 → YYYYMMDD（须通过年月日合法性校验，如 20261301 非法 → 判为批号或错误）。
3. 长度 6 且纯数字 → YYYYMM，缺日补 01 并降级置信度。
4. 含 `-` 或 `/` 或 `.` 或中文「年月日」→ 分段解析。
5. 无法判定 → null，**绝不猜测**。

**歧义防护**：`20260506` 既可能是批号也可能是日期。若该列的表头语义为「生产批号」，则一律按**文本**处理，禁止日期化（这是实测样本中的真实坑）。

## 二、注册证 / 备案凭证号的真实形态

| 形态 | 示例 | 说明 |
|---|---|---|
| 国械注进 | `国械注进20162174128` | 进口第三类 |
| 国械注准 | `国械注准20223170001` | 境内第三类 |
| 国械注许 | `国械注许20210001` | 港澳台 |
| 省简称+械备 | `津械备20230239号` | 第一类备案，**带「号」字** |
| 国械备 | `国械备20190001号` | 进口一类备案 |
| 带旧证号 | `国械注进20162174128（原注册证号：国械注进20162634128）` | 括号内为历史证号 |

**推荐正则**
```regex
^(国械注进|国械注准|国械注许|国械备)[0-9]{8,14}$
^(国械注进|国械注准|国械注许|国械备)[0-9]{8,14}号$
^[京津冀晋蒙辽吉黑沪苏浙皖闽赣鲁豫鄂湘粤桂琼渝川贵云藏陕甘青宁新][械]备[0-9]{8,12}号?$
```
校验失败一律 **D 级**，不允许写入；常见错因是 OCR 把 `注` 识成 `住`、把 `0` 识成 `O`，需在告警中明确提示。

## 三、单位白名单（实测出现）
个、支、盒、袋、包、瓶、套、片、卷、对、台、件
注意「袋」与「包」不可互换（`100个*5包/袋` 表示每袋含 5 包、每包 100 个）；数量口径以单据「数量」列为准，不得由包装描述反推。
